# Full Stack Application Development Capstone Project

**Project Name:** Cars Dealership Review Application

## Overview
A full-stack web application for browsing car dealerships, viewing dealership details, and reading and submitting customer reviews.

## Technologies
- Frontend: React
- Backend: Django and Flask
- APIs: Node.js and Express
- Database: MongoDB and SQLite
- Deployment: Docker, Kubernetes, and IBM Cloud

## Features
- Browse dealership locations
- Filter dealerships by state
- View dealership details and reviews
- Register and log in
- Submit dealership reviews
- Analyze review sentiment
